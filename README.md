Reflection
1. How do you write programs that are maintainable, readable, and adaptable?
   
In Project One I created a CRUD Python module that handled all the database operations (create, read, update, and delete). I used clear method names, comments, and exception handling so the code would be easy to understand and reuse. In Project Two I was able to import that same module and connect it to the dashboard without rewriting the database logic. The advantage of working this way is that the code is reusable and easier to maintain. In the future I could use this same CRUD module for other projects that need to connect a Python application to a MongoDB database.


3. How do you approach a problem as a computer scientist?

When Grazioso Salvare requested the dashboard, I started by reviewing the requirements and the Dashboard Specifications Document. I broke the project into smaller pieces: first connecting to the database, then building the table, then adding the filters and charts. This was different from some earlier courses where the assignments were more step-by-step. In the future, when a client asks for a database or dashboard, I would start by understanding their specific needs, design the queries carefully, and build the application in small, testable pieces.


4. What do computer scientists do, and why does it matter?
 
Computer scientists design and build systems that help people solve real problems. In this project, the dashboard helps Grazioso Salvare quickly find dogs that match the right criteria for different types of rescue training. Instead of searching through large amounts of data manually, they can filter the information in seconds. This kind of work matters because it saves time, reduces errors, and helps organizations like Grazioso Salvare focus on their main goal of training rescue animals.
